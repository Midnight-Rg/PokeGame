# Pokémon Discord Botu

Bu proje, Discord üzerinde çalışan bir Pokémon botudur. Kullanıcılar rastgele Pokémon alabilir, onları besleyebilir, savaştırabilir ve görsellerini görüntüleyebilir.

## Özellikler

- Rastgele Pokémon oluşturur
- Beslenme sistemi (belirli saat aralıklarıyla)
- Savaş sistemi (Fighter ve Wizard sınıfları)
- PokeAPI üzerinden canlı veri
- Pokémon görselini gösterir

## Kurulum

```bash
git clone https://github.com/KULLANICI-ADIN/pokemon-botu.git
cd pokemon-botu
pip install aiohttp
python bot.py
